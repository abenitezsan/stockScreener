¿Cómo se calcula el precio justo?

El precio justo es la mediana de los métodos 1, 2, 3 y 5 que se pueden aplicar. {% if applied %}Aquí se aplican {{ applied | length }} de 4: {{ applied | join(', ') }} → {{ (v.fair_value if v) | fmt }}.{% else %}A este valor no se le puede aplicar ninguno.{% endif %}

  1. Banda de yield: precio al que el dividendo actual rendiría su yield media de los últimos {{ settings.valuation_window_years }} años. D ÷ yield media. Necesita al menos 3 años de dividendos.
  2. PER histórico: el beneficio esperado valorado al PER medio de la empresa. BPA estimado × PER medio. Solo con BPA positivo; no se usa en REITs.
  3. Chowder: precio al que yield + crecimiento del dividendo alcanzan un umbral. D ÷ (umbral − crec. 5a). Umbral del 12 % (15 % si la yield es menor del 3 %; 8 % en utilities con yield de al menos un 4 %).
  4. Rentabilidad objetivo: precio máximo para que yield estimada + crecimiento den un {{ row.target_total_return | fmt('pct') }} anual. D₁ ÷ (objetivo − g). No entra en la mediana: es un techo del precio de compra.
  5. Gordon: valor actual de un dividendo que crece para siempre a ritmo g. D₁ ÷ (r − g), con r = {{ settings.gordon_discount_rate | fmt('pct') }}. Solo en sectores estables (utilities, telecos, consumo básico y REITs).

Precio de compra = el menor entre precio justo × (1 − margen de seguridad {{ row.margin_of_safety | fmt('pct') }}) y el precio máximo del método 4.

D = dividendo ordinario de los últimos 12 meses ({{ (v.dividend_ttm if v) | fmt }}). g = crecimiento del dividendo a 5 años limitado entre 0 y {{ settings.growth_cap | fmt('pct') }} ({{ (v.growth_used if v) | fmt('pct') }}). D₁ = D × (1 + g) ({{ (v.dividend_forward if v) | fmt }}).
